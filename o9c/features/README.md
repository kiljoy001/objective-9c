# o9c language and compiler features

This directory holds Gherkin specifications for the compiler and language
runtime surface. It is separate from `grid/features`, which describes the
mutation grid application built on top of o9c.

Current feature files:

| File | Scope |
| --- | --- |
| `diagnostics.feature` | Structured compiler diagnostics, human messages, tabular diagnostic records, recovery, and grid integration |

These files are requirements and regression targets. They do not imply that
every scenario is already implemented.
